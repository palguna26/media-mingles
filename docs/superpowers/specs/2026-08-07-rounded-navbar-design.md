# Rounded navbar

## Goal

Apply the supplied compact, rounded navbar style while retaining Media Mingles branding, links, and mobile navigation.

## Desktop design

- Use a fixed, inset black navigation bar with rounded corners.
- Place the Media Mingles wordmark at the left.
- Keep the existing primary links centred.
- Keep `Request free audit` as a rounded white button at the right.
- Preserve the existing transparent-to-solid scroll state.

## Mobile and accessibility

- Keep the existing accessible menu button, focus management, and Escape-key close behavior.
- Do not change navigation destinations.

## Validation

- Run lint and a production build.

# Trionn-inspired Media Mingles redesign

## Goal

Give Media Mingles the same dark, minimal, editorial pace as Trionn while keeping Media Mingles branding, copy, routes, media, accessibility, and existing GSAP motion.

## Visual system

- Use black, off-white, and grey as the only UI colours. Project images remain full colour.
- Use Geist for readable body copy, Epilogue for large display type, and Oswald only for small labels and counters.
- Use a compact fixed header: wordmark at left, one primary audit action and menu control at right.
- Use thin rules, large empty areas, oversized display statements, and pill actions sparingly.
- Use the existing video and grain as a dark technical backdrop. Do not use Trionn assets, logo, copy, or illustrations.

## Page structure

1. Preserve the pinned `MEDIA / MINGLES` hero choreography and its audit CTA. Refine its layout and final charcoal state only.
2. Reframe studio and capability sections as spacious editorial statements instead of coloured feature blocks.
3. Add an understated monochrome impact ticker between statement and work sections, using existing site content.
4. Present selected work as large image-led panels with restrained project metadata and one clear action.
5. Keep testimonials, pricing, insights, contact, and footer, but apply the same neutral surface hierarchy and compact controls.

## Motion and responsive behaviour

- Keep existing GSAP timelines, hover effects, and reduced-motion fallbacks.
- Desktop retains pinned and scroll-driven effects. Tablet uses lighter motion. Mobile uses normal flow and no cursor-only interaction.
- No added autoplay audio or heavy video assets.

## Acceptance checks

- No active blue, red, yellow, or green UI surfaces remain outside semantic status messages and project media.
- All primary buttons have dark text on a light fill and visible keyboard focus.
- The hero remains legible at desktop and mobile widths.
- Existing routes and primary actions continue to work.
- Reduced-motion paths remain static and usable.

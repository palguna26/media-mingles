# Reference Implementation Note

This is an internal design note. It must not appear in public website copy.

## Media Mingle

- Transfer: clear service grouping, approachable language, and an easy path to contact.
- Differentiate: Media Mingles will use a darker, more cinematic, production-led system with stronger campaign media and less conventional agency presentation.
- Do not copy: identity, logo, text, contacts, clients, proof, statistics, layouts, or case studies.

## Born & Bred

- Transfer: lead with strong work, connect creative output to business results, and use personality only where proof supports it.
- Apply: campaign-first project stories, direct calls to action, compact result labels, and selective wit.
- Do not copy: jokes, relationship metaphors, emoji language, typography, colours, or section order.

## AMP Agency

- Transfer: let one media asset dominate, keep navigation simple, separate sections clearly, and provide visible motion controls.
- Apply: a calm hero, wide cinematic showreel, clear service architecture, accessible pause and mute controls, and generous spacing.
- Differentiate: Media Mingles remains younger, smaller, faster, and more independent.

## Kindred

- Transfer: editorial restraint, strong image proportions, short strategic copy, generous whitespace, and portfolio pacing.
- Apply: consistent grids, careful crops, quiet metadata, restrained transitions, and boutique-studio detail.
- Do not copy: layout, project presentation, language, identity, or visual system.

## Combined Rule

Use a full dark visual system with warm off-white type and one accent at a time. Most screens stay calm and composed. Animation supports hierarchy and media, while the creative interlude carries the concentrated burst of youthful energy.
